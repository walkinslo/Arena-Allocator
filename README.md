### Требования по реализации

**Память**
- Блок выделяется один раз в конструкторе через `std::unique_ptr<std::byte[]>` — никакого голого `new`
- `capacity` задаётся при создании и не меняется

**Выравнивание**
- `allocate()` обязан выравнивать указатель под `align`
- Используй `std::align` из `<memory>` — не пиши выравнивание руками
- Некорректный `align` (не степень двойки) → `std::invalid_argument`

**Выход за границы**
- Если памяти не хватает — `allocate()` возвращает `nullptr`, не бросает исключений
- `emplace()` при нехватке памяти бросает `std::bad_alloc`

**`emplace<T>`**
- Вызывает `allocate(sizeof(T), alignof(T))`, затем placement new
- Деструкторы объектов **не вызываются** при `reset()` — это осознанное ограничение arena-семантики. Пользователь должен вызвать их сам, если нужно (об этом — в разделе расширений)

**`reset()`**
- Просто сбрасывает offset, память не трогает
- После `reset()` старые указатели формально невалидны (UB при разыменовании) — это нормально для arena
